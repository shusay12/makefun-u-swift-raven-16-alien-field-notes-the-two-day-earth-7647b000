A program that writes one original line — an alien tourist's review of
planet Earth, at most 200 characters — to `/output/entry.txt`.

## Entry

> Came to Earth for the weekend. The locals scoop their pets' droppings
> into little bags and carry them around like treasure. Lovely planet,
> baffling locals - 4/5 stars, would abduct again.

## Run

```sh
python3 main.py
```

Writes `entry.txt` (187 characters) to `/output` by default, or to
`$MAKEFUN_OUTPUT_DIR` when set. Deterministic: every run writes the
same bytes. Standard library only, no network, no file reads.
